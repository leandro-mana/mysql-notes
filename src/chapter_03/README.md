# Chapter 03: SELECT, Filtering & Sorting

This chapter covers the most frequently used SQL statement — SELECT — along with
filtering techniques, pattern matching, sorting, and pagination strategies.

## Notebooks

| # | Notebook | Topics |
|---|----------|--------|
| 1 | `01_select_fundamentals.ipynb` | SELECT, DISTINCT, column aliases, LIMIT/OFFSET, expressions in SELECT |
| 2 | `02_where_and_filtering.ipynb` | WHERE, comparison operators, AND/OR/NOT, IN, BETWEEN, LIKE, REGEXP, IS NULL/IS NOT NULL |
| 3 | `03_sorting_and_pagination.ipynb` | ORDER BY (ASC/DESC, multiple columns), LIMIT with OFFSET, pagination patterns, CAST/CONVERT |

## Key Concepts

- **SELECT** — retrieving columns, expressions, and computed values
- **DISTINCT** — eliminating duplicate rows from results
- **WHERE** — filtering rows with conditions and logical operators
- **Pattern Matching** — LIKE for simple patterns, REGEXP for advanced matching
- **NULL Handling** — IS NULL / IS NOT NULL (never use = NULL)
- **ORDER BY** — sorting results by one or more columns
- **LIMIT / OFFSET** — pagination and top-N queries
- **CAST / CONVERT** — explicit type conversion in queries
